06 / BLENDER & RETARGETING

Blender export

Create motion data through the exporter supported by your FreeMoCap release, then verify the result in Blender.

FreeMoCap → Blender·Version and detector dependent

Do not assume every detector or release exports to Blender. Upstream FreeMoCap's current integrated exporter documents MediaPipe output support. Confirm the current release's compatibility before processing a session for export.

Choose a supported export path

  1. Finish processing the recording in FreeMoCap and note the detector used.
  2. Check the documentation and export controls available for that exact release and detector.
  3. Use the supported Blender integration or documented intermediate file format. UI labels may differ; do not rely on a specific “Generate Blender Scene” button.
  4. If requested, point FreeMoCap to the installed Blender executable and use a compatible Blender/add-on version.

Understand the output

A workflow may generate a Blender .blend scene or another documented exchange format, such as FBX or BVH. These are possible examples, not a promise that every FreeMoCap workflow generates each type. Verify which file was actually produced and retain the session folder.

Files containing 3D skeleton coordinates or CSV data are not automatically animation files or Mixamo-ready armatures. Do not change a file extension to convert formats.

Open and inspect in Blender

  1. Open the generated .blend file directly if the exporter produced one, or use the documented importer for the actual exchange format.
  2. Confirm that the expected skeleton, armature, or motion object appears in the Outliner and viewport.
  3. Scrub the timeline and play the animation. Check the frame range, axis orientation, and scale.
  4. Save a separate working copy before retargeting or changing transforms.

Next step

Once source motion is visible, review Mixamo retargeting. If export fails, see Blender troubleshooting.
