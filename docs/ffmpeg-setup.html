FFmpeg setup

Install FFmpeg on Windows, add its executable folder to PATH, and confirm the terminal can find it.

Windows 10 / 11·About 5 minutes

Do you need FFmpeg? Only install it if FreeMoCap cannot read your original video or you need to convert a format such as 3GP. Preserve your original iPhone recording whenever possible.

Download and extract FFmpeg

  1. Open the official FFmpeg download page and follow its Windows links to a reputable build provider. Windows builds are provided by third parties.
  2. Choose a current Windows Essentials build if the provider offers one. Package names and availability can change.
  3. Extract the archive into a stable folder such as C:\ffmpeg.

Verify that both executables exist in the extracted bin folder:

C:\ffmpeg\bin\ffmpeg.exe
C:\ffmpeg\bin\ffprobe.exe

Add FFmpeg to PATH

PATH tells Windows which folders to search when a command is entered by name.

  1. Open Start, search for Edit the system environment variables, and launch it.
  2. Select Environment Variables.
  3. Under User variables, select Path and choose Edit. A user PATH avoids needing administrator rights.
  4. Choose New and enter the directory containing ffmpeg.exe, for example:
C:\ffmpeg\bin
  1. Confirm each dialog. Close and reopen Command Prompt or PowerShell so the new PATH is loaded.

Verify the installation

Open Command Prompt and run:

where ffmpeg
ffmpeg -version

The first command should show the location of ffmpeg.exe; the second prints the build and version information. If the command is still missing, revisit the PATH entry and see FFmpeg troubleshooting.

Next step

For a 3GP file that FreeMoCap cannot read, follow the video conversion guide. Conversion is optional when the original format is supported.
