05 / CAPTURE & PROCESS

FreeMoCap processing

Bring in a supported video or recording, run the workflow for your version, and review what it produced.

FreeMoCap·Labels and outputs vary by release

FreeMoCap's interface evolves. Use the existing-video or recording-session instructions in the current official documentation for your installed release. Do not copy clips into undocumented internal folders.

Import a video

  1. Open FreeMoCap and select the documented workflow for a new session or for processing existing video.
  2. Select the original iPhone video if your version accepts its container and codec. Otherwise, make an MP4 copy using the conversion guide.
  3. For multi-camera reconstruction, include the synchronized views for the same recording and use a matching successful calibration. A single video is suitable for a single-camera test.
  4. Confirm that the clip loads and the subject is visible before continuing.

Process the recording

  1. Select the imported recording or session.
  2. Choose a detector and options supported by your installed version and intended export workflow.
  3. Start the processing pipeline using the in-app action. Labels such as Continue to Mocap Setup, Process Recording, Run Pipeline, and Start Processing are examples from particular interfaces, not guaranteed names.
  4. Wait until the application reports completion. Processing time depends on video duration, resolution, hardware, number of cameras, and selected method.

Review the tracking result

  • Check that the subject is tracked through the whole clip and that the reconstructed motion is plausible.
  • Look for missing frames, jumps, jitter, identity swaps, drifting joints, or limbs hidden behind the body.
  • If results are poor, improve capture framing/lighting and verify calibration before repeating a short test.

Find the generated files

Open the output directory using the path displayed by the application. The user-reported example for this setup is C:\Users\jakee\freemocap_data\recordings; your configured data directory may differ.

Generated folder names and file sets depend on software version and detector. Examples reported for one workflow include output_data, rtmpose_body_3d_xyz.npy, rtmpose_skeleton_3d.npy, rtmpose_left_hand_3d_xyz.npy, rtmpose_right_hand_3d_xyz.npy, and rtmpose_face_3d_xyz.npy. These are not universal filenames and are not required for every successful run.
